# Hospital Finance & Utilization Analysis Dashboard

A comprehensive multi-tool data analytics project examining the operational capacity, patient activity, and financial health of **455 hospitals**. Using quarterly financial and utilization datasets, this project evaluates key performance indicators (KPIs) across Excel, SQL, Power BI, and Tableau to uncover regional trends, operational bottlenecks, and opportunities for financial improvement.

---

## 📊 Key Metrics & KPIs Analyzed
* **Hospital Capacity:** Total licensed/available beds and bed utilization rates.
* **Patient Activity:** Total patient discharges, average length of stay, and patient volume trends.
* **Financial Performance:** Net patient revenue, total operating expenses, and net operating profit margins.
* **Regional & Comparative Trends:** Cross-hospital benchmarking to identify high-performing facilities and performance gaps.

---

## 🛠️ Tech Stack & Repository Structure

This repository provides end-to-end analysis across multiple business intelligence and data querying platforms:

| File / Dataset | Tool / Format | Description |
| :--- | :--- | :--- |
| `Final_Hospital_Analysis.xlsx` | **Microsoft Excel** | Interactive Excel dashboard featuring pivot tables, KPI cards, and comparative charts. |
| `finalHospital analysis.pbix` | **Power BI** | Dynamic BI report with interactive slicers for drilling down into regional and hospital-level metrics. |
| `hospital Analysis.twbx` | **Tableau** | Packaged Tableau workbook visualizing financial distributions, capacity vs. revenue, and regional trends. |
| `Hospital Analysis.sql` | **SQL** | Data cleaning, aggregation, and exploratory queries used to calculate KPIs and extract insights. |
| `hospital-quarterly-financial-utilization-report-complete-data-set-*.csv` | **Raw Data (CSV)** | Quarterly hospital financial and utilization reports (10 dataset files) serving as the primary data source. |
